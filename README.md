# Home Workout PWA

Jednoduchá offline-first PWA pro iPhone.

## Funkce
- Workout A / B
- 2 pracovní série na cvik
- zápis opakování nebo sekund
- RIR po poslední sérii
- automatický návrh těžší varianty
- rest timer
- historie workoutů
- zapisování tělesné váhy
- lokální ukládání do LocalStorage
- PWA manifest + service worker

## Krátká videa
V každém cviku je připravený "10s demo slot". V další verzi lze ke cvikům přidat vlastní MP4/WebM soubory do assets/videos a nahradit textový slot skutečným <video> prvkem.
